# Security policy

## Supported versions

Security fixes are applied to the latest release and to the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue for an unpatched vulnerability or include credentials, private keys, player data or production secrets in any report.

Include the affected version, expected and observed behavior, reproduction steps and the security impact. Reports will be acknowledged as soon as reasonably possible and coordinated disclosure will be preferred.

## Download verification

Official releases publish a SHA-256 checksum next to the installer. A valid Authenticode signature and a matching checksum should both be verified when a signed release is available.
