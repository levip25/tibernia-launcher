# Privacy policy

Last updated: October 14, 2026

Tibernia Launcher does not create user accounts, request account passwords, display advertising, embed analytics or sell personal data.

The launcher connects to Tibernia update servers over HTTPS to retrieve manifests and game-client files. As with any ordinary web request, the hosting provider may process technical connection data such as the IP address, request time, requested URL and user agent for security, abuse prevention and operational logs. The launcher does not add a persistent advertising or tracking identifier to these requests.

Downloaded files, integrity hashes, selected language and launcher preferences are stored locally on the user's device. Removing the launcher and its local data removes this information from that device.

Questions about this policy may be submitted through the repository's GitHub Issues page. Security-sensitive reports should use GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md).
